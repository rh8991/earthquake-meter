# מד רעידות כיתתי 🌍

אפליקציית ווב לטאבלט שמודדת את התאוצה של המשטח בניסוי "איך נוצרת רעידת אדמה?" (מודל היתקעות–החלקה, Stick–Slip).

התלמידים מושכים בלוק על משטח **עם חיכוך** (נייר שיוף מול נייר שיוף) ו**בלי חיכוך**, והאפליקציה מודדת בעזרת חיישן התאוצה של הטאבלט את הטלטולים שמגיעים למשטח.

## מה יש באפליקציה

- **תצוגה חיה**: התאוצה הנוכחית (m/s²), מדד עוצמה, גרף של 10 השניות האחרונות ומשורה מונפשת עם מים.
- **מהלך המדידה**: גרף של כל ההקלטה על ציר זמן קבוע, שמתמלא תוך כדי מדידה ומסמן את השיא.
- **שני ניסויים**: "עם חיכוך" ו"בלי חיכוך", עם ספירה לאחור כדי שהנגיעה במסך לא תימדד.
- **תוצאות**: תאוצה מרבית, תאוצה ממוצעת ומספר טלטולים מעל סף.
- **השוואה**: שני הגרפים על אותם צירים, עמודות, משפט מסקנה ושאלות לדיון.
- **הגדרות למורה**: סף טלטול, משך הקלטה, כיול מחדש, הורדת נתונים כקובץ CSV.
- **מצב הדגמה**: נתונים מדומים לבדיקה במחשב בלי חיישן.

## הפעלה

האפליקציה היא קובץ אחד, `index.html`, בלי ספריות חיצוניות.

> ⚠️ הדפדפן נותן גישה לחיישן התנועה רק בכתובת **https**. פתיחה ישירה של הקובץ מהמחשב לא תעבוד עם החיישן (מצב ההדגמה כן יעבוד).

אפשרויות לאירוח:

- **GitHub Pages**: ב-Settings ← Pages בוחרים את ענף `main` ואת תיקיית השורש. הכתובת תהיה `https://<user>.github.io/<repo>/`.
- **Netlify Drop**: גוררים את התיקייה ל-https://app.netlify.com/drop.

בדיקה מקומית:

```bash
python -m http.server 8765
```

ואז פותחים את http://localhost:8765.

## שימוש בכיתה

1. מניחים את הטאבלט **שטוח** על המשטח, ליד המשורה עם המים.
2. לוחצים "התחל מדידה" ולא מזיזים את הטאבלט בזמן הכיול (שנייה וחצי).
3. באייפד צריך לאשר גישה לחיישן התנועה.
4. בוחרים ניסוי, מרחיקים את הידיים בזמן הספירה לאחור ומושכים את הקפיץ לאט וברציפות.
5. חוזרים על הניסוי השני ומשווים.
